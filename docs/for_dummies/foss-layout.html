Layouts and checks

The drawing the factory builds from, and the two checks every layout must pass before it goes to the factory.

One tab per program

Pick a program

Each tab says what the program does, where this guide uses it, who makes it, and how to check and install it.

KLayout

Look at chip layouts and check them.

A layout is the drawing the factory builds from: coloured shapes, one colour per layer of material, stored in a GDS file. KLayout opens these files, even huge ones, fast. It also runs the DRC (design rule check): a script that measures every shape and complains when something is too small or too close.

Runs on
Inside the container
Used in this guide
Your first simulation and From gates to a chip layout.
Made by
Matthias Köfferlein.
License
GNU GPL
Website
www.klayout.de

Is it there?

Type this in a container terminal:

$ klayout -v

Install it outside the container

Inside the container it is already installed: nothing to do. These commands are only for using it on your own Ubuntu, without the container.

Ubuntu's package is old. Download the current .deb for your Ubuntu version from klayout.de/build.html and open it to install.

Magic

The classic layout editor, which also reads circuits back out of layouts.

Another layout editor, first written at Berkeley in the 1980s and still used every day. Besides drawing, it can extract a layout: find the devices and wires in the shapes and write them as a netlist, so they can be compared with the schematic.

Runs on
Inside the container
Used in this guide
Add a new device (the Magic Layout row: Create, Run DRC), and inside LibreLane in From gates to a chip layout.
Made by
John Ousterhout and students at UC Berkeley; maintained by Tim Edwards (Open Circuit Design).
License
Berkeley-style open license
Website
opencircuitdesign.com/magic

Is it there?

Type this in a container terminal:

$ magic --version

Install it outside the container

Inside the container it is already installed: nothing to do. These commands are only for using it on your own Ubuntu, without the container.

$ sudo apt install -y magic

Ubuntu's version is older; for real chip work, build it from its GitHub page.

Netgen

Checks that the layout is the same circuit as the schematic.

This check is called LVS, layout versus schematic. Netgen takes the netlist Magic extracted from the layout and the netlist from the schematic, and compares them device by device and wire by wire. If one wire is missing in the layout, LVS finds it before the factory does.

Runs on
Inside the container
Used in this guide
Inside LibreLane in From gates to a chip layout ("0 LVS errors").
Made by
Tim Edwards (Open Circuit Design), the same family as Magic.
License
Free and open source (see its website)
Website
opencircuitdesign.com/netgen

Is it there?

Type this in a container terminal:

$ netgen -batch quit

Install it outside the container

Inside the container it is already installed: nothing to do. These commands are only for using it on your own Ubuntu, without the container.

$ sudo apt install -y netgen-lvs

Ubuntu calls it netgen-lvs (plain netgen is a different program). It is older than the container's.
