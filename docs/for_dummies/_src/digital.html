Before you start

What this section is about

A memristor is a bit

On (low resistance) is a 1, off (high resistance) is a 0. A big voltage pulse writes it, a small one reads it, and it keeps its value with the power off. That's the idea behind RRAM, resistive memory.

From one bit to a chip

The parts go from one memristor in a simulator, to a grid of four, to the way digital designers describe a memory, to real logic gates and a real layout from IHP's PDK.

Which memristor

The Au/HfO₂/Al one from Add a new device: it only switches above +0.8 V or below −0.6 V, so a small read can never change the bit by accident.

Reference

The memristor seen by digital tools

Digital chip tools don't simulate currents. They work with blocks that have pins, a size and a speed. For them a memristor is a black box with two pins, BE and TE. The PDK already has every file they would ask for, made with the Library Manager (see the second slide deck, digital_aspects.tex).

Why so empty?A memristor has no clock and no logic function, so Liberty's usual "delay from input to output" doesn't describe it. Real memory chips solve this by wrapping the memristors in a memory macro (array + the circuits that write and read it), and only the macro gets real Verilog and Liberty views.

Ideas and open questions

Sneak paths
Read the crossbar with the unused wires left unconnected, to see a sneak path turn a 0 into a 1.
Liberty
Leave the memristor's Liberty view as pins only, or invent a simple "memory macro" (e.g. the 2 × 2 crossbar plus its drivers) with real Verilog and Liberty views?
Crossbar
The crossbar part uses a drawing of an HfO₂ crossbar, not a real layout. The PDK's crossbar layouts (crossbar2x2_tio2_au, crossbar4x4_tio2_au) use the TiO₂ device. Make an HfO₂ crossbar layout too?
Models
The HfO₂ model is fixed: its memory starts at x0 and stops at 0 and 1. The TiO₂ models still have the old problem. Fixing them changes nothing in Your first simulation, Add a model and Corners and Monte Carlo if their testbenches start at x0=0, but about 60 screenshots show x0=0.3 in xschem and would need re-shooting. Glossary

Words you'll meet

RRAM
Resistive RAM: memory that stores bits as the resistance of memristors.
non-volatile
Keeps its data without power (like a USB stick, unlike a computer's main RAM).
Verilog
A language to describe digital circuits as text.
synthesis
Turning a Verilog description into real logic gates (Yosys does this).
place and route
Deciding where every block goes on the chip and drawing the wires between them (OpenROAD, LibreLane).
Liberty (.lib)
A data sheet for tools: how fast, how much power, which pins.
LEF
A block's outline and pin positions, without the inside details.
1T1R
One transistor, one resistor (memristor): the usual RRAM bit-cell.
digital twin
A simple digital model that behaves like the real device for ones and zeros, without the physics.
waveform
A picture of signals changing over time, as GTKWave draws them.
flip-flop
A one-bit memory inside digital logic, updated at each clock tick.
standard cell
One ready-made logic gate from a PDK's library, like sg13g2_nand2_1.
crossbar
A grid of row and column wires with a memristor at every crossing: one bit per crossing.
write disturb
Writing one cell changes a neighbour by accident, because the neighbour got too much voltage.
sneak path
An unwanted route for current through neighbouring cells of a crossbar.
