Part 1 · the idea

One memristor, one bit

Computers store everything as bits, zeros and ones. A memristor can hold a bit without any power, because its resistance stays where you left it. That is the whole "digital side" of a memristor: it is a tiny memory cell that keeps its data with the power off, the idea behind RRAM (resistive RAM).

1

Bit 0 and bit 1

bit 1
The memristor is on: low resistance (Ron), a lot of current flows.
bit 0
The memristor is off: high resistance (Roff), very little current flows.
write 1 (SET)
A short, big positive voltage pulse switches it on.
write 0 (RESET)
A short, big negative pulse switches it off.
read
A small voltage, too small to switch anything. Measure the current: big means 1, small means 0.
Why the HfO₂ memristorThe Au/HfO₂/Al memristor from Add a new device only changes above +0.8 V or below −0.6 V. So a 0.2 V read can never change the bit by accident.

10

The voltage

11

The current

The top plot shows the current through the memristor, in mA.

How to read it Read 1 (0–100 ns): almost no current. The memristor is off. Write 1: the current jumps to 2.4 mA as the memristor turns on. Read 2: 0.4 mA. Same small read voltage as read 1, a hundred times more current: the memristor is now on. Write 0: a short dip, then almost nothing as it turns off again. Read 3: almost no current. Back to off.
12

Read the bit

Look at the end of the ngspice window: the three reads, in µA (microamps, millionths of an amp).

The ruleMore than 100 µA means 1, less means 0. So the bit was 0 at the start, 1 after writing a 1, and 0 again after writing a 0. Between the pulses the voltage was 0 and nothing changed: the memristor remembered.

Part 3 · about 5 minutes

A write that is too weak

The memristor only switches on above +0.8 V. What happens if the write pulse is only 0.7 V? Change one number and find out.

16

Edit the code block

Double-click on the text of the code block, at the bottom of xschem.

17

The vset line

The Edit Properties box opens with the whole code block. The line to change is .param vset = 1.2.

18

Go to the end of the line

Click anywhere on the vset line, then press End. The cursor jumps to just after 1.2.

19

Type 0.7

Press Backspace three times to delete 1.2, type 0.7 (box 1), then click OK (box 2).

20

Netlist, then Simulate

Click Netlist (1), then Simulate (2), and wait about 10 seconds.

21

The new result

The same windows open again. The voltage plot now only reaches 0.7 V during the write 1.

22

No switching

Look at the current plot. Its scale is now in µA, not mA: the current stays tiny all the time.

What happened 0.7 V is below the +0.8 V threshold, so the memristor never switched on. It stayed a plain 50 kΩ resistor. 14 µA during the write is just Ohm's law: 0.7 V ÷ 50 000 Ω. Read 2 is 4 µA, the same as read 1.
23

All reads say 0

The ngspice window confirms it: 4 µA, 4 µA, 4 µA. The write failed, so the bit stayed 0.

Why this mattersReal memory chips must write with enough voltage, but they also must read with a small enough one. The gap between the two (0.2 V for reading, more than 0.8 V for writing) is what makes the memory safe.
Try itBefore closing, try other values: vset = 0.9 still writes a 1 (it switches more slowly); vreset = -0.5 can't erase it. Each time: Edit, Netlist, Simulate, then close the plots and ngspice.

Part 4 · what digital tools need

The memristor seen by digital tools

Digital chip tools don't simulate currents. They work with blocks that have pins, a size and a speed. For them a memristor is a black box with two pins, BE and TE. The PDK already has every file they would ask for, made with the Library Manager (see the second slide deck, digital_aspects.tex).

Why so empty?A memristor has no clock and no logic function, so Liberty's usual "delay from input to output" doesn't describe it. Real memory chips solve this by wrapping the memristors in a memory macro (array + the circuits that write and read it), and only the macro gets real Verilog and Liberty views.
Part 5 · many bits

From one bit to a memory

One bit isn't much. Put memristors where rows and columns of wire cross and you get a crossbar: 4 bits in a 2 × 2 grid, 16 in 4 × 4. The PDK already has both, crossbar2x2_tio2_au and crossbar4x4_tio2_au, with layouts checked by DRC and LVS (see the crossbar slide decks).

28

How you pick one bit

To write or read one bit, you put the voltage on its row and ground its column. Only that crossing sees the full voltage.

The catch: sneak pathsCurrent can also sneak around through the neighbours (row → other device → other column → …). Writing one bit can disturb the others a little, and reading can be fooled. The crossbar slide decks show this happening in simulation. Real chips add a transistor (1T1R) or a selector to each bit to block those paths.

A small Verilog block that decides which row and column to drive. Synthesize it with Yosys to see it become logic gates.

One transistor plus one memristor per bit. This PDK has no transistors (on purpose), so the transistor would come from the IHP SG13G2 PDK that openPDKcreator already handles: a mixed schematic with parts from two PDKs.

Glossary

Words you'll meet

RRAM
Resistive RAM: memory that stores bits as the resistance of memristors.
non-volatile
Keeps its data without power (like a USB stick, unlike a computer's main RAM).
Verilog
A language to describe digital circuits as text.
synthesis
Turning a Verilog description into real logic gates (Yosys does this).
place and route
Deciding where every block goes on the chip and drawing the wires between them (OpenROAD, LibreLane).
Liberty (.lib)
A data sheet for tools: how fast, how much power, which pins.
LEF
A block's outline and pin positions, without the inside details.
1T1R
One transistor, one resistor (memristor): the usual RRAM bit-cell.
sneak path
An unwanted route for current through neighbouring cells of a crossbar.
