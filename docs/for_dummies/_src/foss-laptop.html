Git

Downloads projects and remembers every version of them.

Git keeps the whole history of a folder of files: every change, who made it and when, so you can always go back. GitHub is a website that stores Git projects for everyone to see; git clone downloads one to your computer. openPDKcreator, the memristor PDK and the container's launcher all live on GitHub.

Runs on
Your laptop
Used in this guide
Install from scratch: downloading openPDKcreator, the PDK and the container launcher.
Made by
Linus Torvalds (the creator of Linux) in 2005; now a large community.
License
GNU GPL 2.0
Website
git-scm.com

Is it there?

Type this in a terminal on your laptop:

$ git --version

Install it

$ sudo apt install -y git

Already done in Install from scratch.

Podman

Runs containers: a ready-made computer inside your computer.

A container is a complete, packed Linux system with programs already installed and set up. Podman downloads it and runs it, kept apart from the rest of your laptop. Installing forty chip-design programs one by one would take days; with a container it is one download. Podman does the same job as the better-known Docker, but needs no administrator program running in the background.

Runs on
Your laptop
Used in this guide
Install from scratch: the launcher uses it to start the container.
Made by
Red Hat and the Podman community.
License
Apache 2.0
Website
podman.io

Is it there?

Type this in a terminal on your laptop:

$ podman --version

Install it

$ sudo apt install -y podman

Already done in Install from scratch.

IIC-OSIC-TOOLS

The toolbox: dozens of chip-design programs in one container.

A container image with almost every open chip-design program already installed and working together: all the ones in these tabs, and many more. It also brings open PDKs from real factories (SkyWater sky130, GlobalFoundries gf180, IHP SG13G2). It opens a Linux desktop in a browser window, the container desktop you see in the screenshots. This guide uses version 2026.10.

Runs on
Your laptop (it is the container itself)
Used in this guide
Every section from Your first simulation on: all the programs below run inside it.
Made by
The Institute for Integrated Circuits (IIC) at Johannes Kepler University Linz, Austria.
License
Apache 2.0
Website
github.com/iic-jku/IIC-OSIC-TOOLS

Is it there?

Type this in a container terminal:

$ echo $IIC_OSIC_TOOLS_VERSION

Install it

Follow Install from scratch, steps D and E: download its launcher with Git, then start it. The first start downloads about 20 GB.
