Before you start

Two PDKs side by side

openMemristorPDK only has memristors, on purpose. Real chips also need transistors, and for those you borrow a second PDK: IHP SG13G2, a real, open 130 nm process from the IHP research institute in Germany, with transistors, logic gates and memories. The two PDKs stay separate; a circuit can simply use parts from both.

Part 1 · 2 minutes

It's already in the container

The IIC-OSIC-TOOLS container from Install from scratch comes with several PDKs, IHP's among them. Check it's there.

1

Open a terminal

In the container desktop (the browser window), click the terminal icon in the bottom panel.

2

List the container's PDKs

Click inside the terminal, type this and press Enter:

$ ls /foss/pdks
What you seeihp-sg13g2 is the one we use. The others are other open processes: sky130A (SkyWater, 130 nm), gf180mcuD (GlobalFoundries, 180 nm) and a second IHP flavour. Nothing to install for simulating with IHP's transistors.
Part 2 · about 2 minutes

Give openPDKcreator its own copy

To open IHP's PDK in openPDKcreator, it needs its own copy, in openPDKcreator/data/ihp-sg13g2. One command downloads it (about 1.2 GB) from IHP's GitHub page.

3

Download it

In the same terminal (it starts in /foss/designs, which is your openPDKcreator folder), type this and press Enter. Wait until the prompt comes back, about a minute.

$ python3 main.py fetch
DoneThe last lines list the four folders it downloaded: documentation, test data, cell libraries (libs.ref) and tool files (libs.tech).
"already exists"?Then you already have the copy and nothing was downloaded. That's fine: go on.
4

Close the terminal

Type exit and press Enter.

Part 3 · about 3 minutes

Open IHP's PDK next to ours

The same start command as always, with --gui instead of --gui-memristor, opens a second openPDKcreator window on IHP's PDK. Your memristor window stays open behind it.

5

Start it

In the laptop's terminal (the one from step 1 of Your first simulation, not the browser), in the openPDKcreator folder, type:

$ ./start_eda_container.sh --gui
[INFO] iic-osic-tools_openpdkcreator_uid_1001 is already running.
[INFO] VNC session: http://127.0.0.1:8081/?password=abc123&autoconnect=true&resize=scale  (NOT the 'localhost' form -- see header comment)
[INFO] Launching the IHP SG13G2 GUI inside the container ...
ThenA last line of letters and numbers (an ID for the started program). Go back to the browser.
6

A second window

A new openPDKcreator window opens at the top left. Its title ends in data/ihp-sg13g2/ihp-sg13g2: that is how you tell it from the memristor one.

7

IHP's Library Manager

In the new window, click the Library Manager tab.

8

IHP's libraries

Click sg13g2_stdcell (box 1). The Cells list (box 2) fills with IHP's standard cells: the logic gates (and, or, flip-flops…) a digital chip is built from.

sg13g2_stdcell
Logic gates, ready to place on a chip.
sg13g2_io
The pads that connect the chip to the outside world.
sg13g2_sram
Ready-made memories (SRAM).
sg13g2_pr
Single devices: transistors, resistors, capacitors. openPDKcreator shows this list empty, because these devices have no cell files of their own; you use them straight from xschem, as in The digital side.
A different list?If you made your own libraries in this window, they show up too, marked (project).
9

Close the IHP window

Click the X at the top-right of the IHP window. The memristor window is still open behind it.
