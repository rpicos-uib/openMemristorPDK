About 10 minutes

Step by step

Real memory chips put a transistor in series with every memristor: the 1T1R cell. The transistor is a door: only the cells whose door is open can be written or read, so neighbours are safe and sneak paths are blocked. openMemristorPDK has no transistors, so this cell borrows one from IHP's SG13G2 PDK.

1

Three wires

Do Add IHP's PDK first if you haven't: it explains where IHP's PDK lives. This part only uses the copy that comes with the container.

word line (wl)
Goes to the transistor's gate. 3.3 V opens the door, 0 V shuts it.
bit line (bl)
Goes to the memristor. +1.5 V writes a 1, 0.2 V reads.
source line (sl)
Goes to the other side of the transistor. +2.0 V writes a 0 (the current flows backwards).

2

Pick the 1T1R testbench

In the memristor window’s Library Manager, with openmemristorpdk_pr selected, click memristor_hfo2_al_1t1r_tb.

3

Open it in xschem

On the Schematic row, click Open in xschem.

4

The 1T1R cell

Box 1 is the cell: the memristor on top, IHP’s transistor sg13_hv_nmos below it. Box 2 holds the three voltages.

sg13_hv_nmos
IHP's "high-voltage" n-type transistor, made for up to 3.3 V. Its symbol comes from /foss/pdks/ihp-sg13g2, the memristor's from openMemristorPDK: one drawing, two PDKs.
.lib ... cornerMOShv.lib mos_tt
Loads IHP's transistor models at the typical corner (TT), like the corner library of Corners and Monte Carlo.
pre_osdi ... psp103.osdi
IHP's compiled transistor model (PSP 103), loaded next to our compiled memristor model.
5

Netlist, then Simulate

Click Netlist (1), then Simulate (2), and wait about 10 seconds.

6

Two plots and the console

Two plot windows and the ngspice window open.

7

The current

The top plot is the current into the bit line, in mA.

How to read it 100–200 ns: the bit line is at 1.5 V, but no current flows. The door is shut, so the write does nothing. 300–400 ns: the same write with the door open. Current flows (1.7 mA) and the memristor switches on. 400–500 ns: read 3 gives 0.25 mA, a 1. 500 ns: the write 0 pulls current backwards (the dip) and switches it off.
8

The four reads

Look at the end of the ngspice window.

The bits0, then still 0 after the write with the door shut, then 1, then 0. The read with the door open gives 255 µA instead of 400 µA: the transistor adds a little resistance, but it's still far above the 100 µA line.
9

Close the current plot

Click Quit in the top plot window.

10

The three wires

Now the other plot is fully visible: the three wire voltages over time.

How to read itThe red word line drops to 0 V exactly while the first write pulse (blue) is on: the door is shut. The orange source line only moves for the write 0.
11

Close the voltage plot

Click Quit in this plot window too.

12

Close the simulator

Click inside the white ngspice window, type quit and press Enter.

13

Close xschem

Click the X at the top-right of the xschem window. You changed nothing, so it closes straight away.

Try itEdit the code block and set vwl = 1.2, the gate voltage of IHP's ordinary low-voltage transistors: the door barely opens. Read 3 gives only about 47 µA, which counts as a 0 even though a 1 was written, and the write 0 can't change anything. Each time: Netlist, Simulate, close the plots and ngspice, and don't save when you close xschem.
