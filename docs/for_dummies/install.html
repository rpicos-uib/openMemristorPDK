Install from scratch

Everything you need, downloaded and set up on a new Linux computer: two programs, openPDKcreator, the memristor PDK, and the container with all the chip-design tools. You only do this once per computer. You only ever need to click whatever is inside the red box, or type exactly what is in a black box.

Only once, on a new computer

Five steps, A to E

Skip this section if openPDKcreator already works on this computer. On a new Linux computer (Ubuntu or similar), these five steps download everything: two programs, the openPDKcreator tool, the memristor PDK, and the "container" with all the chip-design programs. You need an internet connection and about 35 GB of free disk space. Do them in a terminal: press Ctrl + Alt + T to open one.

A

Install git and podman

Type these two lines, pressing Enter after each. The computer asks for your password (the one you log in with). Nothing shows on screen while you type it, that's normal.

$ sudo apt update
$ sudo apt install -y git podman
What these aregit downloads projects from GitHub. podman runs the container, the separate computer-inside-the-computer where all the chip-design programs live.
B

Download openPDKcreator

This makes a folder and downloads the openPDKcreator tool into it, as openPDKcreator. It's the same folder step 2 of Your first simulation uses.

$ mkdir -p ~/Documentos/rodrigo
$ cd ~/Documentos/rodrigo
$ git clone https://github.com/rpicos-uib/openpdkcreator-toolkit.git openPDKcreator
You should seeOne line, in your computer's language. On a Spanish computer:
Clonando en 'openPDKcreator'...
C

Download the memristor PDK

The memristor PDK goes inside the openPDKcreator folder, as openMemristorPDK:

$ cd openPDKcreator
$ git clone https://github.com/rpicos-uib/openMemristorPDK.git
Clonando en 'openMemristorPDK'...
D

Download the container launcher

IIC-OSIC-TOOLS, from the university in Linz that builds the chip-design container, has the script that starts it. openPDKcreator looks for it in ~/eda/IIC-OSIC-TOOLS:

$ git clone --depth 1 https://github.com/iic-jku/IIC-OSIC-TOOLS.git ~/eda/IIC-OSIC-TOOLS
E

Start it for the first time

Still in the openPDKcreator folder, run the same start command as step 2 of Your first simulation:

$ ./start_eda_container.sh --gui-memristor

The first time, it downloads the container, about 15 GB (it can take half an hour or more), and then prepares it for a few more minutes with no progress shown. Don't close the terminal until it finishes. It ends like this:

[INFO] iic-osic-tools_openpdkcreator_uid_1001 does not exist -- creating it.
[INFO] Podman rootless mode detected.
[INFO] Adding --userns=keep-id for Podman rootless mode.
[INFO] Container does not exist, creating iic-osic-tools_openpdkcreator_uid_1001 ...
[INFO] With --userns=keep-id, Podman makes an ID-mapped copy of the image on the first start of each image version.
[INFO] This can take several minutes without any progress output and needs about as much disk space as the image. Do not interrupt it.
[HINT] CONTAINER_USER=0 CONTAINER_GROUP=0 avoids the copy, see README section 5.1.
[INFO] Verifying that the container stays up (up to 2s) ...
[INFO] To access the VNC session, open a browser and navigate to http://localhost:8081/?password=abc123
[INFO] VNC session: http://127.0.0.1:8081/?password=abc123&autoconnect=true&resize=scale  (NOT the 'localhost' form -- see header comment)
[INFO] Launching the openMemristorPDK GUI inside the container ...
DoneEverything is installed. Now go to step 3 of Your first simulation (open the browser). From now on, starting it takes seconds: just do steps 1 and 2 there.
Two links?Use the 127.0.0.1 one (the same as in step 3). The localhost one doesn't work with this setup.
